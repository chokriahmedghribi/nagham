# نغمة (Nagham) — مشغّل موسيقى لأندرويد

تطبيق Kotlin + Jetpack Compose + Media3. الموسيقى تُبثّ من الإنترنت عبر **Audius** (كتالوج مفتوح ومجاني)،
والكلمات من **LRCLIB**. كل بيانات المستخدم (قوائم، مفضلة، سجل استماع) تُحفظ على الهاتف فقط.

## التشغيل
1. ثبّت Android Studio (Koala أو أحدث) ثم افتح مجلد المشروع، وانتظر مزامنة Gradle.
2. وصّل هاتفك (تصحيح USB) أو شغّل محاكياً، ثم Run.
3. لملف APK جاهز: Build ▸ Build Bundle(s)/APK(s) ▸ Build APK(s) (النسخة release موقّعة بمفتاح التطوير فيمكن تثبيتها مباشرة).

## الميزات
- بحث وفلترة بالنوع، مكتبة، مفضلة، قوائم تشغيل، قائمة انتظار، عشوائي وتكرار
- تشغيل بالخلفية مع إشعار تحكم وشاشة القفل
- كلمات الأغاني المتزامنة (تظهر عند توفرها)
- توصيات تُحسب على الجهاز من سجل استماعك (بدون حساب أو تتبّع)
- معادل صوتي (Equalizer) + تعزيز الجهير + منحنيات جاهزة
- انتقال متلاشٍ بين الأغاني (0–12 ثانية)
- مؤقت نوم (دقائق، نهاية الأغنية، أو «ذكي» بخفض تدريجي للصوت)
- أوضاع الاستماع: جري / نوم (النوم يفعّل المؤقت الذكي تلقائياً)
- ملخص سنوي (Wrapped) من تبويب «ملخصي»

## هيكل الكود
- `data/` قاعدة Room وواجهات Audius/LRCLIB والمستودع
- `playback/` الخدمة والمشغّل والمعادل والتلاشي ومؤقت النوم
- `reco/` التوصيات والأوضاع والملخص السنوي
- `ui/` شاشات Compose

## ملاحظات
- المصدر خلف `MusicRepository` فيمكن استبدال Audius بمصدر آخر (مثل Jamendo أو خادم Navidrome شخصي) بتعديل ملف واحد.
- الانتقال المتلاشي تلاشٍ متتابع وليس تداخلاً حقيقياً بين أغنيتين.
